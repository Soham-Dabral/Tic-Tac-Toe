### V2 TIC-TAC-TOE
It is a simple tic-tac-toe implemented without OOPs.
This is also the final project of CISCO Python Essentials-1 and I have solved it using my own way.

Game is very simple to play, you just need to enter a valid position in the grid, and play it as it is usually played.
This version doesn't have a multiplayer version (soon will make it too, for now you can see v1 in this repository, its kind of bad UI, but it will be fixed)
The Computer plays as your opponent and the moves played by it are random.
It is planned to made more smarter in the upcoming days.

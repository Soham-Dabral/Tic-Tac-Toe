# Tic-Tac-Toe v1_OOPS (Python)

A simple two-player Tic-Tac-Toe game built in Python using Object-Oriented Programming (OOP). This project was created to practice Python fundamentals, class design, game logic, input validation, and state management.

## Features

* Two-player gameplay (Player X vs Player O)
* Object-Oriented design
* Turn-based game loop
* Input validation

  * Prevents non-integer inputs
  * Prevents out-of-range coordinates
  * Prevents moves on occupied cells
* Automatic win detection

  * Rows
  * Columns
  * Both diagonals
* Draw detection
* Console-based interface

## How to Play

* Player **X** always starts first.
* Enter the row and column (0–2) when prompted.
* Players alternate turns until one player wins or the game ends in a draw.

Example:

```text
Player X's Turn
Row: 1
Column: 2
```
